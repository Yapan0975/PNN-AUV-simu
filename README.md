# PNN-AUV-simu

Simulation and benchmark code for the paper:

> **A Leakage-Free Multi-Method Benchmark for Underwater Acoustic Target Recognition,
> and an Energy–Accuracy Analysis of a Simulated Physical-Reservoir Sensing Front End**
> (manuscripts in preparation, 2026).

This repository contains every simulation script and the per-claim raw result
(`*_results.json`) that each number, table, and figure in the paper is computed
from, plus the recording-ID split manifest. With the random seeds pinned in the
scripts, the JSON results regenerate deterministically.

**Scope.** The paper's benchmark contribution (leakage-free UATR evaluation) is an
*empirical* result on real recordings; the physical-reservoir front end and the
energy ledger are a *numerical feasibility study* (a differentiable device forward
model + a bottom-up power model) — there is **no hardware, pressure-vessel, or
sea-trial measurement**.

## Circuit-level validation (this `spice` branch)

The `spice` branch adds a circuit-level (ngspice) check of the resonator
reservoir. The abstract transfer function is realised as 32 Tow–Thomas
state-variable band-pass sections with a datasheet-grounded op-amp macromodel
(TI OPA2376), simulated in ngspice, and the measured |H|² is fed back into the
same leakage-free IARA classifier. The circuit reproduces the abstract model's
accuracy (0.398 vs 0.402, five-class, overlapping CIs) but corrects its energy
(246 mW measured, not the ~13 mW originally estimated), yielding an honest
energy–accuracy–mode design space. Scripts under `pnnsim/spice/`:

| Script (`pnnsim/spice/`) | Artefact |
|---|---|
| `spice_common.py` | ngspice batch runner + Tow–Thomas section + single-pole op-amp macromodel |
| `spice_reservoir.py` | extract the 32-mode bank \|H\|² / measured Q / noise / power (writes `spice_reservoir.npz` + JSON) |
| `spice_iara_eval.py` | circuit \|H\|² vs abstract \|H\|² on real IARA, 15 seeds, recording-level |
| `spice_mode_sweep.py` | accuracy-vs-power mode-count Pareto (4→32 modes) |
| `spice_energy_update.py` | energy ledger recomputed with the circuit-measured front end (5.0×/1.46×, d\*=18.5%) |

**Requires ngspice.** Set the `NGSPICE_DIR` environment variable to your ngspice
install's `Library` directory — the one containing `bin/ngspice_con.exe` and
`share/ngspice` (the conda-forge ngspice build uses this layout). Run order:
`spice_reservoir.py` (needs ngspice; writes `spice_reservoir.npz`) → then
`spice_iara_eval.py` / `spice_mode_sweep.py` / `spice_energy_update.py`. The
`.npz` cache and figure PNGs are regenerated by the scripts and are not committed.

## Data (not redistributed here — use the public sources)

- **IARA** hydroacoustic archive (1 825 recordings, 128 kHz): Zenodo
  https://doi.org/10.5281/zenodo.15758636
- **ShipsEar** underwater vessel-noise database (second-corpus leakage replication):
  via its public redistribution (Santos-Domínguez et al., *Applied Acoustics*, 2016).

To extract features from raw audio, place the IARA volume zips (`A.zip`…`H.zip`)
and `iara.xlsx` in a sibling `IARA-data/` directory. Large feature caches (`*.npz`)
are regenerated by the scripts on first run and are intentionally not committed.

## Key scripts → where they appear in the paper

| Script (`pnnsim/`) | Paper artefact |
|---|---|
| `iara_leakage_test.py` | by-recording vs by-segment leakage tables (IARA, ShipsEar) |
| `phase0_iara_bench.py` | multi-method leakage-free benchmark (2–5 class) table + figure |
| `phase0_iara_stats.py` | macro-F1, cluster-bootstrap CIs, fixed-reservoir, PAT-vs-reservoir paired test (n=15, p=0.45), confusion matrix |
| `iara_detection_roc.py` | detection ROC-AUC / AP / P_d@P_fa table + figure |
| `iara_linear_control.py` | four-rung detection ablation (trivial / linear / MLP / reservoir) |
| `iara_subset_robustness.py` | alternate balanced draws + 716-record natural-imbalance draw |
| `iara_volume_split.py` | volume-aware test (leave-one-volume-out; cross-volume detection) |
| `iara_stratified.py` | sea-state (ambient-noise) stratified accuracy figure |
| `energy_ledger.py` | itemised Monte-Carlo power ledger (27×/9×, d*≈1.5%) table + figure |
| `energy_sensitivity.py` | front-end / ASIC / sub-Nyquist / analog-support sensitivity table |
| `iara_drift_recal.py`, `iara_drift_sweep.py` | real-IARA drift recalibration figure + recovered-fraction sweep |
| `iara_extra_experiments.py` | ResNet 15-seed (5- and 4-class) + 4/8/16 s window sweep |
| `iara_kernel_rank.py` | reservoir kernel-rank / memory-capacity diagnostic |
| `phase0_acoustic.py`, `phase1a_*.py`, `phase1b_*.py` | synthetic Phase-0/1 device-proxy validation |
| `core.py`, `iara_dataset.py`, `iara_logmel.py`, `models_bench.py`, `phase0_iara.py` | shared modules / data loaders |

Each `*_results.json` is the exact output consumed by the manuscript.
